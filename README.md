# 📂 Data Extraction

## 📌 Overview
This Excel file is designed as a **data extraction and lookup practice task**.  
It focuses on retrieving specific information from a structured dataset using **Excel formulas**, rather than manual filtering or editing.

The task simulates a real-world scenario where required details must be extracted accurately from a large table using lookup logic.

---

## 🎯 Task Objective
To extract specific data fields such as **Country**, **Customer Name**, and **Order Date** from a given dataset based on provided reference values.

The task is divided into multiple questions (Q1, Q2, etc.), each testing a different aspect of data retrieval using Excel functions.

---

## 🗂️ Dataset Structure
The dataset contains order-related information, including:

- Order IDs
- Customer-related details
- Country information
- Dates associated with transactions

Separate output columns are provided where extracted values must be displayed.

---

## 🔍 Nature of the Task
This is a **formula-driven task** that emphasizes:

- Correct use of lookup and reference functions
- Accurate cell referencing
- Logical data extraction
- Handling of text and date values

No manual copy-paste is involved; all outputs are expected to be generated using Excel formulas.

---
